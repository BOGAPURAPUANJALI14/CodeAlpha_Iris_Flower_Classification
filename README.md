# CodeAlpha Data Science Internship – Project Pack

This pack contains starter-to-complete Python workflows for all four tasks listed in the CodeAlpha Data Science task sheet.

## Projects
1. Iris Flower Classification
2. Unemployment Analysis with Python
3. Car Price Prediction with Machine Learning
4. Sales Prediction using Python

## How to run
- Open https://colab.research.google.com/
- Create a new notebook.
- Upload or paste the corresponding `.py` file, or copy its contents into notebook cells.
- Run cells from top to bottom.
- For Tasks 2–4, upload the relevant CSV dataset when prompted.
- Check the printed column names. If your dataset headers differ, update the column mapping/target variable noted in the script.

## Important dataset notes
- Task 1 uses Scikit-learn's built-in Iris dataset.
- Task 2 expects Region, Date, and an unemployment-rate column. The script maps common column-name variants.
- Task 3 expects a numeric `Selling_Price` target and supports mixed numeric/categorical predictors. Adapt the target name if your dataset differs.
- Task 4 expects a numeric `Sales` target. Adapt the target name if your dataset differs.

Do not report sample metrics as your final results. Run the scripts on the exact dataset supplied or approved by CodeAlpha and record the actual output.
